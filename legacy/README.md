# Legacy reference scripts

These files are earlier reference scripts. They are kept for traceability and
are not part of the maintained `cyclotron_sim` package.

| File | Purpose |
| --- | --- |
| `main.py` | Earlier PyQt front end. |
| `test2.py` | Early prototype of the GUI and plotting workflow. |
| `Draw_circle_nov24.py` | Small geometry/plotting experiment. |

The maintained application is `cyclotron_gui.py` in the repository root. It
loads `ZykloSim_nov24.ui` and uses Matplotlib for plotting.

The legacy scripts may expect their original working-directory layout and are
not covered by the automated tests.
